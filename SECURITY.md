# Security Policy

## Supported Versions

Security fixes are applied to the latest maintained version of each package and to the current `main` branch.

Older releases may remain available for compatibility reasons, but they should not be assumed to receive security updates.

| Package | Supported versions |
| ------- | ------------------ |
| TypeScript / JavaScript | Latest release |
| Python | Latest release |
| Go | Current `main` branch |
| Java | Latest release |
| C | Current `main` branch |

## Reporting a Vulnerability

If you believe you found a security issue, please report it privately.

Preferred channel:
- Open a private security advisory on GitHub, if available for this repository.

Fallback channel:
- Open a regular issue only if the report does not expose users to immediate risk.

When reporting, include:
- affected package or language
- affected version
- steps to reproduce
- impact assessment
- proof of concept, if available

## Response Process

The project will try to:
- acknowledge the report within a reasonable time
- validate whether the issue is reproducible
- prepare a fix or mitigation when the issue is confirmed
- publish the fix in the supported package or branch

## Disclosure

Please avoid public disclosure before the issue has been reviewed and, when necessary, fixed.
